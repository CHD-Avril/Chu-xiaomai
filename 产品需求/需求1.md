## 🎯 项目目标回顾（根据现有功能）

这个页面核心功能包括：

* 显示当前歌单征集状态
* 用户提交歌曲
* 实时显示投稿列表和喜欢数
* 点赞（Vote）和搜索功能
* 每日推荐推荐内容
* 管理员设置征集期和公告

这些行为需要实时数据交互，非常适合用前端框架 + 后端服务组合实现。

## 🧠 主要 Vue 逻辑拆分（建议详细需求）

| 功能模块        | Vue 组件                                                    | 说明                         |
| ----------- | --------------------------------------------------------- | -------------------------- |
| 首页动态列表      | `Home.vue` + `SongList.vue`                               | 通过 Pinia 载入歌单数据，支持点赞、搜索和排序 |
| 投票 & 点赞     | `VoteButton.vue`                                          | 单首歌点赞逻辑；显示累积喜欢数            |
| 投稿表单        | `SubmitForm.vue`                                          | 输入歌名/歌手后上传                 |
| 每日推荐        | `DailyPicks.vue`                                          | 每天随机抽选展示                   |
| 管理后台        | `PeriodSettings.vue`, `NoticeBoard.vue`, `AdminLogin.vue` | 管理员权限逻辑按角色展示               |
| Supabase 交互 | `api/supabase.js`                                         | 提供统一 API 调用，管理数据库连接        |

📍 建议用 **Pinia** 管理全局状态（比如当前投稿列表、用户投票状态等），比单靠本地变量更易维护。

# ✨ 页面互动 & 效果建议（提升体验）

为了让页面更有趣、流畅、并且适合手机端显示，这里给出一些建议：

---

## 🔄 1. 优雅的加载 / 过渡动画

* 页面加载时用 **渐显动效（fade-in）** 让 UI 更柔和。
* 点赞按钮可以用 **心形短动画** 提示点赞成功。
* 使用 Vue `<transition-group>` 渐显列表项变化（对于动态增删特别好）

📌 技术提示：Vue 的过渡系统 + CSS 动画（transform/opacity）对手机渲染性能友好。

---

## 📊 2. 动态榜单排序动画

当用户改变排序方式（按时间 / 按喜欢数）时，可以加上列表**重新排列的过渡效果**，提升体验。

---

## 📅 3. 每日推荐卡片

用**轮播卡片式设计**展示「每日推荐」5首歌：

* 卡片左右滑动（touch/swipe）
* 轻柔浮动阴影

这比单一列表更有吸引力。

---

## 📱 4. 手机优先适配

必做：

* 顶部导航固定
* 按钮大触控面积
* 弹窗操作可由底部上滑弹出（类似移动 App）

📌 可配合 CSS Grid + Flexbox 做响应式布局。

---

## 📣 5. 通知弹窗 / Toast 系统

* 提交成功 / 喜欢成功 / 操作失败等提示，可用小弹窗过渡显示。
* 建议用 Vue 自制 Toast 组件。

---

## 🔐 6. 管理员模式体验

管理员登录后：

* 显示独立侧边栏
* 时间段设置用日期选择器
* 自动弹窗显示最新公告

---
